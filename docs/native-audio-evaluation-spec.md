# SpeechPractice native-audio experiment

Status: local, single-page MVP. Record and replay a sample, enter an API key for the current request, and ask `gpt-audio-1.5` for qualitative feedback directly from the audio. The app does not use Whisper, a delegated model, numeric scores, or historical comparisons. Its statements about clarity, pronunciation, articulation, mumbling and accents are unvalidated model observations, not diagnosis or human listener judgments.

The app binds to loopback, checks the remote address and host, uses Django CSRF protection, and has no login, database or saved recordings. Input and converted WAV exist in a temporary directory during processing; normal exit and handled failures clean it up, while a crash may leave OS temporary files. The key is supplied per request and is not persisted or logged. Audio is sent to OpenAI with `store=false`, but [provider retention rules](https://developers.openai.com/api/docs/guides/your-data) still apply. Recordings are bounded to 10 MB and two minutes; browser capture stops at 118 seconds to allow encoder padding. Calls have a 90-second timeout, no automatic retries and a per-process guard against simultaneous submissions. A failed or disconnected call can still incur a charge.

Before drawing conclusions, compare feedback to the speaker's own listening and, where possible, another human listener. Test repeated takes, clearer and faster speech, naturally varied accents, and background-noise samples. Stop or redesign if the model invents problems, penalizes accent rather than understandability, or confidently judges unusable audio. This is an exploratory hypothesis, not a validation study.

The previous Django product and its datasets remain outside this app's runtime path. Do not deploy the loopback development server as a hosted service.
